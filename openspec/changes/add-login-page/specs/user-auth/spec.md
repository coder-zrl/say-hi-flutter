## ADDED Requirements

### Requirement: 用户登录认证
系统 MUST 提供用户登录认证功能，用户在访问应用主要功能前需要通过用户名和密码验证。

#### Scenario: 成功登录
- **WHEN** 用户输入有效的用户名和密码
- **THEN** 系统验证凭据并跳转到主页
- **AND** 显示成功提示信息

#### Scenario: 登录失败
- **WHEN** 用户输入无效的用户名或密码
- **THEN** 系统显示错误提示信息
- **AND** 保持在登录页面

#### Scenario: 用户名验证
- **WHEN** 用户输入用户名
- **THEN** 验证用户名仅包含英文、下划线、数字
- **AND** 长度必须大于0且不超过50个字符
- **AND** 不符合条件时显示相应错误提示

#### Scenario: 密码验证
- **WHEN** 用户输入密码
- **THEN** 验证密码长度大于0且不超过30个字符
- **AND** 不符合条件时显示相应错误提示

#### Scenario: 应用启动
- **WHEN** 用户启动应用
- **THEN** 显示登录页面作为首页
- **AND** 用户必须完成登录才能访问其他功能

### Requirement: 登录表单界面
系统 SHALL 提供清晰易用的登录表单界面，包含用户名和密码输入框以及登录按钮。

#### Scenario: 表单显示
- **WHEN** 登录页面加载
- **THEN** 显示用户名输入框、密码输入框和登录按钮
- **AND** 输入框有相应的标签和占位符文本
- **AND** 密码输入框应隐藏输入内容

#### Scenario: 表单交互
- **WHEN** 用户与表单交互
- **THEN** 提供实时的输入验证反馈
- **AND** 登录按钮在表单验证失败时禁用
- **AND** 支持键盘提交操作

### Requirement: 导航状态管理
系统 SHALL 管理用户的登录状态和页面导航。

#### Scenario: 登录状态保持
- **WHEN** 用户成功登录
- **THEN** 系统保持用户登录状态
- **AND** 防止未登录用户访问受保护的页面

#### Scenario: 登录后导航
- **WHEN** 用户成功登录
- **THEN** 自动导航到主页
- **AND** 用户可以通过底部导航栏访问聊天、发现和个人中心页面
